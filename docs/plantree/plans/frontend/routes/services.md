## 组件与细节

- **列表**（GET /services?limit=100 本机过滤）：命令列 mono 截断（tooltip 全值）；
  状态徽标（● green 运行 / ○ gray 停止 / ✕ red 失败）+ 失败行展开显示 exit_code。
- **行内操作**（F42）：运行中显示 [⏹ 停止] [⟳ 重启] [⋯]；停止/失败显示 [▶ 启动] [⋯]；
  按钮图标 16px + 8px 间隙，操作后按钮短暂 loading（请求往返），状态由推送翻转（F43）。
- **实时化**（F43）：本 tab 打开时订阅在线主机服务状态（列表页级别），
  ServiceStatus 到达 → 对应行徽标翻转 + 行背景闪 gray-200 200ms；
  日志增量不进列表（只在抽屉打开时消费）。
- **创建/编辑抽屉**（F41）：右抽屉 400px：名称、命令（mono）、参数（行编辑，
  每行一个 arg）、重启策略分段器（no / always）；编辑态预填。
- **删除守卫**：running 服务的 ⋯ 菜单「删除」置灰 + tooltip「先停止」；
  DELETE 成功 toast。
- **日志抽屉**（F44/F45）：打开先拉快照（GET /services/{id}/logs）；
  [⟳ 实时] 切换 WS tail：增量 append、自动滚底（用户上滚则暂停 +
  底栏显示「已暂停」+ 「回到最新」按钮）；ERROR/WARN 行按关键字着色（red/amber）。
  WS 断开：日志区尾部插灰字 `--- 实时断开 ---` + 自动重连一次。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 表格 5 行骨架 |
| 无服务 | 空态「还没有常驻服务」+ [创建服务] |
| 主机离线 | amber 通栏；列表照常（历史状态），操作禁用 |
| 启停请求中 | 对应按钮 spinner；请求失败 toast 还原 |
| 日志为空 | 抽屉「暂无日志输出」 |
| 日志加载失败 | 抽屉错误条 + 重试（不影响列表） |

## 交互细节

- 失败服务行：名称旁 ⚠ amber 图标；行展开显示 exit_code 与最近日志尾部 3 行。
- 底栏计数 mono；「1 失败」部分 red-1000 可点击过滤失败行。
- 抽屉宽度 1440+ 屏幕为 640px，以下 560px。
