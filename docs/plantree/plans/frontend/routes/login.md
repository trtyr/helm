## 组件与细节

- 表单仅两项：username / password；autofocus username；Enter 提交。
- 按钮 loading 态：文案不变 + 左侧 14px spinner（bcrypt 校验可达数秒，按钮禁用 +
  「验证中…」次要文案），**不做超时假成功**。
- 密码可见切换：输入框右侧眼睛图标（gray-900 → hover gray-1000）。
- 登录成功：存 JWT（localStorage）→ 跳 `?redirect=` 或 `/dashboard`，无过渡动画。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| 默认 | 空表单，按钮 gray-700 高对比（Vercel 黑白按钮） |
| 校验失败（401） | 表单下方 ⚠ 行内错误「用户名或密码错误」，输入框边框 red-1000 |
| 提交中 | 按钮 disabled + spinner，输入禁用 |
| 网络错误 | 行内错误「无法连接服务器」+ 重试链接 |
| 已登录访问 /login | 直接重定向 /dashboard |

> **M1 适配**：dashboard 路由在 M4 提供——M4 之前默认跳转目标为 `/`（→ /hosts），
> 其余交互不变（已在 M1 实现并验证）。

## 交互细节

- 密码错误后：password 清空并 focus，username 保留。
- 连续失败无锁定（后端无此语义），但错误文案第三次起追加「默认凭据 admin/admin123 仅开发环境」提示。
