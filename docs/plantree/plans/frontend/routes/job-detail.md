# 路由：/jobs/:id — 任务详情

Role: route-spec
Status: active
Related: [路由地图](README.md)、[功能 F27/F28](../topics/feature-inventory.md)、GET /jobs/{id}、WS /jobs/{id}/stream

## 功能清单

- F27 Job 详情（元信息 + 输出回放）
- F28 输出实时流（running 时自动接入）

## 组件与细节

- **元信息**：GET /jobs/{id}；耗时 = finished-started（运行中显示已运行 Xs 计数器）；
  参数列为 args 数组逐个 chip（mono）。
- **输出回放**（F27）：job.output 整段渲染（一次注入，无打字机动画）；
  stderr 混排按顺序输出（后端合并存储——与实时模式一致语义）。
- **实时流**（F28）：status=queued/running 时自动连 WS /jobs/{id}/stream：
  二进制帧增量 append；滚底规则同服务日志（用户上滚暂停 + 「回到最新」）；
  终态到达（job 翻转 succeeded/failed）→ 断 WS → 拉一次 GET 刷新元信息 →
  状态徽标翻转 + 底栏「传输完成」。
- **[⤢ 全屏]**：输出块全屏（Fullscreen API），Esc 退——长输出排查场景。
- **[⧉ 复制]**：复制 output 全文，toast「已复制 1,204 字节」。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 元信息骨架 + 输出区灰块 |
| 不存在（404） | 「任务不存在」错误卡 + 返回链接 |
| queued | 状态 ● blue「排队中」，输出区「等待执行…」 |
| running（WS 已连） | 流式输出 + 底栏「实时已连接」 |
| running（WS 断） | 底栏 amber「实时断开，10s 后重试」+ 手动重连 |
| 无输出（成功空命令） | 输出区「（无输出）」灰字 |
| 超时/取消 | 状态 ⏱ amber；元信息 exit_code — |

## 交互细节

- 运行中每秒刷新耗时计数器（前端本地，不重查）。
- WS 重连上限 3 次，超限转 5s 轮询 GET（降级保底）。
