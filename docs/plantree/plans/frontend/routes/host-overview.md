- F25 快速命令执行（本 tab 主操作）

## 组件与细节

- **快速执行**：命令输入 mono；`$` 前缀图标；Enter 即运行（Shift+Enter 换行不支持——单行）；
  参数输入框（逗号分隔提示）；运行 → POST /exec → toast「任务已创建」→
  跳 `/jobs/:id`（自动接实时输出 F28）。
- **指标快照**：三行水平条（60px 宽迷你 bar + mono 数值）——数据取
  GET /metrics?host_id=&limit=1 的各指标最新值；磁盘 >90% 数值 amber-1000 + ⚠。
- **Agent 卡**：多 agent（同 host 多条）时纵向列表逐个展示；
  「查看详情」链接到 /hosts?view=agents 并前端过滤本主机。
- **最近任务**：GET /jobs 过滤本 host 前 5 条：job_id 前 4 位 mono + 命令截断 +
  状态色字（✓ green / ✗ red / ⏱ amber）+ 相对时间。
- 离线守卫：离线时快速执行卡顶部同框架页的 amber 通栏，运行按钮禁用
  （tooltip「主机离线」）。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 快速执行卡骨架 + 左右列卡片骨架 |
| 无 Agent | 右列 Agent 卡空态「未注册——主机上线后自动出现」 |
| 无指标 | 指标快照区「暂无上报数据」（新装 agent 30s 内出现首批） |
| 无任务 | 最近任务「还没有执行过任务」+ 快速执行引导箭头（首次使用引导） |
| Error | 各卡独立错误态 + 重试（同仪表盘互不拖垮原则） |

## 交互细节

- host_id 复制：点击整行复制（mono 全值在 tooltip），toast「已复制」。
- 指标快照 30s 轮询（同心跳节奏）；页面不可见时暂停（document.visibilitychange）。
