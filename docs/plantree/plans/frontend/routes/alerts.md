## 组件与细节

- 数据：GET /alerts?page=&limit=（服务器分页）；级别列 label-12 徽标
  （warning → amber 系底色；后端预留 level 字段）。
- **F56 主机跳转**：行点击（或主机名链接）→ `/hosts/:id/metrics`，
  URL 带 `?metric=cpu.usage` 参数，指标页对应卡片高亮 200ms + 滚动到视口。
- 「实测 → 阈值」列：mono，箭头 gray-900，实测值 red-1000 加粗。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 8 行骨架（info 条先渲染——静态内容） |
| Empty | 「没有告警记录——一切正常 ✓」（green-1000 ✓，正向空态） |
| Error | 错误卡 + 重试 |
| 分页尾页删除后空 | 回退上一页 |

## 交互细节

- 30s 轮询第一页（新告警到来时页头出现「有新告警 · 刷新」提示条，不自动跳页
  ——避免阅读位置被打断）。
