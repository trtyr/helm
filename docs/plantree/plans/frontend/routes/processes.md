## 组件与细节

- **拉取**（POST /processes/list {agent_id}）：手动刷新 + 自动间隔可选
  （关闭/5s/10s/30s，默认 5s；页面不可见暂停）；刷新 = 全量替换，无闪烁动画，
  但 PID 集合变化时底栏计数更新。
- **搜索**（F47）：前端本地过滤（名称子串 / PID 前缀）；与排序叠加；
  清空按钮 ×。
- **排序**：表头三列可排序（PID/CPU/内存），当前列 ↓/↑ 指示。
- **高危着色**：CPU > 80% 或内存 > 500MB 的数值 amber-1000（信息提示非错误）。
- **杀进程**（F48）：行 ⋯ 菜单「结束进程」→ 确认模态（大号 mono 显示 PID + 名称 +
  「该操作不可恢复」red-1000 警示）→ POST /processes/kill → 结果语义：
  `{ok:true}` toast ✓「进程 4201 已结束」；`{ok:false}`（HTTP 200）toast ⚠
  「进程不存在（可能已退出）」；自动刷新列表。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 表格 8 行骨架 |
| 主机离线 | amber 通栏 + 禁刷新（保留最后快照数据，顶部标注「快照 · 12:01」）|
| 无进程数据 | 空态「无法获取进程列表」（罕见——离线时已拦截） |
| 搜索无结果 | 「没有匹配 "xxx" 的进程」+ 清除链接 |
| kill 请求失败 | toast red + 列表不变 |

## 交互细节

- ⋯ 菜单仅「结束进程」一项（克制；未来扩展位）。
