# 路由：/hosts/:id — 主机详情布局框架

Role: route-spec
Status: active
Implemented: M1 落地（helm-console 762800f，验收见对应里程碑 verify-m*.mjs）
Related: [路由地图](README.md)、[host-overview](host-overview.md) 等 8 个 tab 规格

## 职责

本规格定义 **tabs 容器**（主机头 + 页签导航 + tab 内容区）；
各 tab 内容见独立规格：[概览](host-overview.md) / [终端](terminal.md) / [文件](files.md) /
[服务](services.md) / [进程](processes.md) / [网络](network.md) / [指标](metrics.md) /
[任务](host-tasks.md)。

## 组件与细节

- **主机头数据**：GET /hosts 单查 + 30s 轮询（在线徽标翻转）；hostname 变更即时反映。
- **返回链接**：label-13 gray-900，← 图标 16px；点击回 /hosts（保留原过滤的 URL state）。
- **[编辑标签]**：弹 360px 小模态（chip 编辑器，同创建表单交互）；保存后头部即时更新。
- **[⋯ 更多]**：编辑主机（复用创建抽屉）/ 删除主机（同列表页确认流）/ 复制 host_id（mono，toast）。
- **tab 与 URL 同步**：`/hosts/:id/<tab>`；刷新/直链/分享均落到具体 tab；
  tab 间切换不重新拉取主机头（缓存）。
- **tab 可用性守卫**：离线主机的终端/文件/服务/进程/网络 tab 仍可进入，但内容区顶部
  显示通栏提示条「主机离线——操作将在其上线后可用」（amber-100 底 + amber-1000 文字），
  并禁用操作按钮；概览/指标/任务 tab 不受影响（历史数据）。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| 主机加载中 | 头部骨架（标题灰条 + 徽标灰点），tabs 可见但禁用 |
| 主机不存在（404） | 页内错误卡「主机不存在或已删除」+ [返回列表] |
| 删除后 | 全局 toast「已删除」→ 自动跳回 /hosts |
| Tab 切换 | 150ms 无动画（仅指示条滑动）；各 tab 自管 loading |

## 交互细节

- 键盘：`←/→` 在 tab 间移动焦点（可用性）；⌘1–⌨8 直达 tab（终端页聚焦 xterm 时豁免）。
- 页签图标：每 tab 文字前 16px 线性图标（概览◔ 终端▮_ 文件▤ 服务⚙ 进程☰ 网络⇄ 指标∏ 任务◷）。
