## 组件与细节

> **单栏而非双栏的决策**：1Panel 式「本地 | 远端」双栏的前提是浏览器能枚举本地目录，
> 而本产品 API 语义是 push/pull（upload 从 Server 推到远端、download 拉回 Server 侧路径），
> 浏览器本地无文件树可管理——双栏会制造虚假的操作模型。故采用远端单栏 + 传输队列，
> 与 API 语义一致。

- **列目录**（POST /files/list {path}）：默认从 `/` 开始；目录双击进入（行内单击 = 选中，
  显示 ⋯ 菜单）；面包屑每段可点（前端拼路径重查）。
- **排序**（F39）：表头点击（名称/大小/修改时间，目录恒定排前）；刷新按钮重查当前路径。
- **上传**（F36）：点 [⬆ 上传] → 文件选择 → 预确认小模态（本地文件名/大小 →
  目标路径输入，默认当前目录 + 文件名）→ POST /files/upload（同步等待）；
  传输项显示 进度（后端无分块进度回调——前端以请求 pending + 完成翻转模拟：
  进行中不定假进度，显示「传输中…」+ 不可取消提示；完成显示 checksum_ok）。
- **下载**（F37）：文件行 ⋯ 菜单「下载」→ 确认（远端路径 → 本地保存路径输入）→
  POST /files/download → 完成显示 checksum_ok + 保存路径回显。
- **校验结果**：checksum_ok=true → ✓ green；false → ✗ red + 「文件可能损坏」警示行。
- **传输队列**：右下固定卡（modal 材质 12px）；多项并行显示多行；完成后条目保留
  30s 或手动 ×；离线时队列入口禁用。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading（列目录） | 表格 6 行骨架 |
| 空目录 | 「此目录为空」居中 + 上传引导 |
| 主机离线 | amber 通栏 + 全部操作禁用（面包屑保留路径展示） |
| 路径错误（不存在） | 错误卡「路径不存在或无权限」+ [回到 /] |
| 上传/下载失败 | 队列项 ✗ red + 错误摘要 + [重试] |
| 校验失败 | 队列项 ⚠ amber + checksum 提示（见上） |

## 交互细节

- 权限列 mono 显示（`-rw-r--r--` 截断为 `rw-r--r--`，tooltip 全值）。
- 大小人类可读（B/KB/MB/GB，1 位小数）；时间 `MMM DD HH:mm`（同年省年份）。
- 路径输入替代：面包屑末段点击可变为 mono 输入框直接改路径（回车跳转，Esc 还原）。
