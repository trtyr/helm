## 组件与细节

- **数据模型**：GET /metrics?host_id=&limit=N（N 由范围推导：实时 60 / 1h 120 /
  6h 144 / 24h 288——按 30s 采集密度）。指标名映射：
  `cpu.usage`→CPU、`mem.percent`→内存、`disk.usage`→磁盘、
  `net.rx_bytes|net.tx_bytes`→网络（双系列）。
- **图表类型选择**：主指标 = 折线 + 8% 面积填充（单系列 blue-1000；
  网络双系列 blue + teal）；**sparkline**（次要 + 仪表盘 F11）= 无轴 polyline。
  全站不引重型图表库大套件，仅折线/面积两种形态（决策 006 详述）。
- **阈值线**：cpu/mem/disk 卡画 90% 红色虚线（`--ds-red-1000` 40% 透明），
  与后端阈值联动的心智模型。
- **实时流**（F51）：`实时` 范围时连 WS /metrics/stream，按 host_id 过滤本机消息；
  新点 push 尾 + 超窗 shift 头（60 点）；非实时范围不连 WS（静态查询）。
  断线：卡片右上红点 + 「实时断开」；恢复清空重拉。
- **时间轴**：mono label-12，仅首/中/尾三个刻度；hover 十字线 + tooltip
  （时间 + 值，mono tabular）。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 4 图灰块骨架 |
| 无数据（新主机） | 全空态「暂无上报数据——Agent 每 30s 上报一批」 |
| 部分指标缺失 | 对应卡空态，其余照常（互不拖垮） |
| 实时断线 | 见上；历史区间仍可见 |
| 查询失败 | 错误卡 + 重试（保范围选择） |

## 交互细节

- 范围切换 150ms 内完成（数据已缓存区间直接渲染，未缓存才请求）。
- 图表响应式：卡宽 <480 时隐藏左轴数字、保留阈值线。
- 次要指标默认折叠（▸/▾），状态记 localStorage。
