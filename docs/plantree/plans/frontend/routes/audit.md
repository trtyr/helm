## 组件与细节

- **动作徽标**：label-12 mono，gray-200 底圆角 4px（如 `exec` `login` `file_upload`）；
  动作色语义不做（审计是中性记录）。
- **行展开**（F63）：点击行（或 ▸）展开 detail JSON 树视图：
  缩进 2 空格、键 label-13 gray-900、值 mono；长值折叠（点击展开全值）；
  展开动画 150ms 高度过渡。资源列内容 = detail 的摘要（前端推导：
  agent_id/hostname/job_id 等字段取首个非空）。
- 分页服务器端；URL query 同步 page。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 8 行骨架 |
| Empty | 「暂无审计记录」 |
| Error | 错误卡 + 重试 |
| detail 为空对象 | 展开区「（无附加详情）」 |

## 交互细节

- 展开状态跨分页不保留（回到本页重新展开）。
- 时间列 hover tooltip 显示完整 ISO 时间戳。
