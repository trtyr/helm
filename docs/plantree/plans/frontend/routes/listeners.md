## 布局与留白

监听器数量少（通常 1–3 个）——**卡片网格而非表格**。

```text
┌ Content ──────────────────────────────────────────────────────────┐
│ 监听器                                         heading-24         │
│ Agent 接入的 gRPC 监听端点                    copy-13  [+ 创建监听器]│
│                                        24px↓                     │
│ ┌ 默认监听器 ─────────────────────────┐ ┌ 内网备用 ──────────────┐│
│ │ ● running                            │ │ ○ stopped              ││
│ │ grpc://0.0.0.0:50051 (mono)          │ │ grpc://10.0.0.2:50053  ││
│ │ 专用 token：••••••••（👁 显示/复制）   │ │ 专用 token：（空，回退 ││
│ │ 创建 Sep 01 · 运行中自 Sep 03        │ │ 全局 token）           ││
│ │           [⏹ 停止]  [⋯]              │ │        [▶ 启动]  [⋯]   ││
│ └──────────────────────────────────────┘ └────────────────────────┘│

```

## 组件与细节

- **状态徽标**（F68）：● green 实心 + running（附 2s 呼吸微动效——唯一允许的持续动效，
  表达「正在监听」）；○ gray 空心 + stopped。
- **token 显示**：默认掩码 `••••••••`；👁 点击显形 5s 自动掩回；旁附复制按钮
  （复制明文，toast「已复制」）。「空，回退全局」为 gray-900 说明文字。
- **启停**（F66）：卡片主按钮（宽 96px h-32）；请求中 spinner；成功后徽标翻转。
  停止操作不需确认（可逆）；启动失败 toast 错误摘要（如端口占用）。
- **创建模态**（F65）：360px：名称（必填）、地址（`ip:port`，placeholder
  `0.0.0.0:50054`，mono）、协议（仅 grpc，禁用态标注）、专用 token（可选，说明文案：
  「留空则使用全局 HELM_SERVER_TOKEN」）。
- **[⋯] 菜单**（F67）：编辑（复用创建模态）/ 删除（确认模态——运行中删除二次警示
  「停止后删除将断开其上所有 Agent 连接」）。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 3 卡骨架 |
| Empty | 「没有监听器」+ 说明「Server 启动时默认 seed 一个，或手动创建」+ [创建] 按钮 |
| 启停请求中 | 按钮 spinner + 卡片操作禁用 |
| 删除运行中 | 确认模态红色警示（见上） |
| Error | 错误卡 + 重试 |

## 交互细节

- 卡片右上 ⋯ 菜单与底部主按钮并存：主按钮 = 最高频动作（启/停）。
- 地址列 mono；端口与 IP 各占 tooltip 一行（复制地址复制完整 `ip:port`）。
