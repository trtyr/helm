## 组件与细节

- **主题**（F04）：分段器二选一；切换即时（CSS 变量组交换，无闪烁——先设
  `color-scheme` 再换类）；Topbar 快捷图标与本页选中态双向同步。
- **会话**：JWT exp 本地解码（atob payload.exp），剩余时间每分钟重算；
  「续期」= 重新登录（无 refresh token 端点——见 open-questions）。
- **系统信息**（F69）：全部只读——本页是「关于」性质，不放任何可写设置
  （后端无用户偏好端点）；后端地址 = 前端运行时的 API base（env 注入）。
- **Agent 安装命令**：折叠块（▸ 展开），内容按连接模式两个 tab：
  反向（`helm-agent --agent-id <id> --server-addr <addr> --token <token>`）/
  正向（forward 版 + mTLS 预置说明链接到 run-and-deploy 文档）；命令块
  mono + [⧉ 复制]（token 值以 `••••` 掩码显示，复制时复制真实值）。

## 交互细节

- 退出登录：confirm（「确认退出？」）→ 清 token → /login。
- 安装命令的 `<token>` 提示：输入框让用户粘贴自己的 token 生成完整命令
  （前端不持有 server_token——安全边界：控制台不知道全局 token，让用户自己填）。
