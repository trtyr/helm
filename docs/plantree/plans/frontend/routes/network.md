## 组件与细节

- 拉取：POST /net/info {agent_id}，进入 tab 一次性 + 手动刷新（无自动轮询——
  接口信息低频变化）。
- 接口卡：标题 = 接口名（label-16）+ 类型推断标注（lo → 回环；eth/enp/wlan → 常规；
  docker/veth/br → 容器/网桥——前端静态映射，未识别不标注）；
  地址列表为 mono chip（IPv4 与 IPv6 分色：同 gray 系但 IPv6 加 `v6` 小徽标）。
- 地址 chip 点击复制（toast）。
- 主机名行：底部独立一行，与接口卡区分（这是 NetInfo 的 hostname 字段）。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 3 卡骨架 |
| 主机离线 | amber 通栏 + 保留最后快照标注时间 |
| 无接口数据 | 空态「暂无网络信息」 |
| 刷新失败 | 错误卡 + 重试 |

## 交互细节
