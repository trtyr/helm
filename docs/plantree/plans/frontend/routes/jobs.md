## 组件与细节

- 主机过滤下拉：GET /hosts（id ↔ hostname 映射缓存）；
  URL query 同步 `?status=&host=&page=`（可分享/回退）。
- 运行中行：状态 ● blue-1000（区别于成功的 green）+ 行内 12px spinner；
  10s 轮询刷新运行中 job 状态（或依赖全局通知流触发刷新）。
- 命令列 mono 截断 + tooltip 全值；退出码 mono（0 = green、非 0 = red、— = 未结束）。
- 行点击 → /jobs/:id。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 8 行骨架 |
| Empty | 「还没有任务历史」+ 「去主机执行命令」链接（/hosts） |
| 过滤无结果 | 提示 + 清除过滤链接 |
| Error | 错误卡 + 重试 |
| 主机列表加载失败（过滤下拉） | 下拉禁用 + toast；列表本身不受影响 |

## 交互细节

- 状态 chips 计数来自最近一页查询的推导（或 /jobs 全量 limit=1 的 total——
  采用后者：每 status 一次轻查询，仅首次进入时计算）。
- 分页与过滤变更 = 服务器端查询（page/limit 传后端），本地零假分页。
