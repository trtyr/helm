# 路由：/notifications — 通知中心

Role: route-spec
Status: active
Related: [路由地图](README.md)、[功能 F57–F61](../topics/feature-inventory.md)、GET /notifications*、WS /notifications/stream（决策 009）
Related: 全局层（Topbar 铃铛与下拉）在本文下方「全局元素」节一并定义

## 功能清单

- F57 铃铛 + 未读角标（全局 Topbar）
- F58 下拉小卡片（全局 Topbar）
- F59 通知中心页（筛选 + 分页）
- F60 标记已读（单条/全部）
- F61 实时推送（toast + 角标脉冲）

## 全局元素：铃铛与下拉（Topbar，所有路由可用）

```text
Topbar 右侧：
…  [🔔 ●3]  [◐ 主题]  [avatar ▾]
      ↑ 铃铛 20px；角标 blue-1000 圆点 8px（有未读时）；数字 ≥10 显示 ●9+

点击铃铛 → 下拉面板（menu 材质：12px 圆角 + 浮层阴影，宽 360px，max-h 480px）：
┌ 通知 ●3                        [全部标为已读] ┐
│ ──────────────────────────────────────────── │
│ ● 主机 web-1 已上线                    2m 前 │ ← ● = kind 点：
│ ◌ 主机 db-1 已下线                    18m前 │   online green
│ ● 主机 web-1 已上线                   1h 前 │   offline gray
│ ◐ 预警：cpu.usage = 96.2（阈值 90）   3h 前 │   alert amber
│ （未读行左侧 2px blue 指示条；已读行 gray-900 弱化）│
│ ──────────────────────────────────────────── │
│                    查看全部 →                  │ ← 链接到本页
└──────────────────────────────────────────────┘
```

- 下拉打开时拉 `GET /notifications?limit=10`；列表项点击：跳转目标
  （online/offline → /hosts/:id/overview；alert → /hosts/:id/metrics?metric=…）
  **并隐式标记该条已读**。
- [全部标为已读]：POST /read-all → 角标即时归零 + toast「已标记 N 条」。

## 组件与细节

- **F57 角标**：数据源双通道——WS /notifications/stream（即时 +1）+ 30s 兜底轮询
  unread-count（校准）；WS 新通知到达：铃铛角标数字滚动 +1 + 铃铛图标 200ms
  scale 脉冲一次（克制的动效）。
- **F61 toast**：右下角（避开右下传输队列位——传输队列优先，toast 上移）：
  kind 点 + message 截断 2 行 + [查看]；4s 自动消失；同 5s 窗口多条合并为
  「N 条新通知」。
- **F59 行结构**：状态点列 8px；内容列 label-14；主机列链接；时间相对。
- **F60**：单条已读 hover 浮出按钮（未读行才有）；全部已读需 confirm 模态
  （「将 12 条通知标为已读？」）；操作后列表即时刷新弱化态。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 8 行骨架（含下拉场景：下拉 5 行骨架） |
| Empty | 「暂无通知——主机上下线与预警会出现在这里」 |
| 只看未读空 | 「没有未读通知 ✓」正向空态 |
| WS 断线 | 页头 label-12 amber「实时推送已断开，轮询中」；页面功能不受影响 |
| 标记失败 | toast red + 状态回滚 |

## 交互细节

- 下拉面板点外部关闭；Esc 关闭；`N` 键盘快捷键打开下拉（power user 向）。
- 通知内容里的主机名渲染为链接（message 为文案，主机列已有链接——内容列不加链接，避免重复）。
