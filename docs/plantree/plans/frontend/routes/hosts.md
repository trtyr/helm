## 功能清单

- F12 主机列表（分页）、F13 标签过滤、F14 在线徽标
- F15 创建主机、F16 编辑、F17 删除、F18 设标签（标签编辑入口）
- F20 Agent 列表、F21 Agent 详情、F22 注销、F23 卸载、F24 标签同步

本页是双视图：`/hosts`（默认：主机表）与 `/hosts?view=agents`（Agents 表），
页签切换不跳路由（查询参数，保持滚动位置语义简单）。

## 组件与细节

- **状态列**（F14）：20px 单元内 8px 圆点——在线 green-1000 实心；离线 gray-900 空心
  （1.5px 描边）；stale amber-1000 50% 透明。tooltip 显示「在线 / 离线（最后心跳 x 前）/ 心跳超时」。
- **标签列**：chip（label-12，gray-200 底 + gray-400 边框 + 圆角 4px，最多显示 3 个 +
  `+n`）；点击 chip 即加入过滤（F13 与工具行联动）。
- **工具行**：左标签多选下拉（checkbox 列表，选中变顶部 chip 可移除）；右搜索框
  （200px，主机名前端本地过滤，与后端 tag 过滤叠加）。
- **创建/编辑抽屉**（F15/F16）：右侧抽屉 400px，遮罩 40% 黑；表单纵向 24px 间距：
  hostname（必填）、conn_mode 分段器（反向/正向，选中项 blue-1000 边框）、
  addr（仅正向显示，placeholder `ip:50052`）、标签输入（回车成 chip）。
- **删除**（F17）：行尾 `⋯` 菜单 → 模态（标题 red-1000）→ 输入 hostname 确认 → DELETE。
- **Agent 操作**（F21–F23）：Agents 视图行点击开右抽屉 480px：dl 基本信息
  （agent_id mono 全宽可复制、版本、注册、心跳、在线大徽标 32px）+ 操作区
  （编辑标签 / 注销 danger / 卸载 danger + 「同时移除二进制」checkbox）。
- **分页**：页码 + 每页条数（20/50/100）；总数 mono 显示。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| Loading | 表格 8 行骨架（行内灰条） |
| Empty（无主机） | 表格区空态：主机图标 + 「还没有主机」+ [创建主机] 按钮 |
| Empty（过滤无结果） | 「没有匹配 [标签] 的主机」+ [清除过滤] 链接 |
| Error | 表格区错误卡 + 重试（保留过滤条件） |
| 删除中 | 行半透明 + 行首 spinner；失败 toast 还原 |
| Agents 视图 Empty | 「暂无注册 Agent——在目标机安装 helm-agent 后出现」 |

## 交互细节

- 行点击 → `/hosts/:id/overview`（新标签页打开 = 中键/Ctrl，普通点击当前页跳转）。
- 在线状态 30s 轮询刷新（与后端心跳 10s/超时 30s 匹配），无动画直接翻转。
- `⋯` 行菜单项：编辑 / 删除（主机视图）；详情 / 标签 / 注销 / 卸载（Agents 视图）。
