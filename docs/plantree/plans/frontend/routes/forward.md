## 组件与细节

- **目标模式**：按主机名（下拉：GET /hosts 过滤 conn_mode=forward）或
  按地址（手输 `ip:port`）；选中的主机名校验 addr 非空（空则提示「该主机未配置地址」）。
- **执行**：POST /forward/exec——**同步等待**（HTTP 保持至远端执行完）；
  按钮全程 spinner + 「拨号执行中…」；超时提示（前端 60s 上限，
  与后端 http_json 超时一致）。
- **结果**：exit_code 色（0 green / 非 0 red）；输出块样式复用 job 详情终端块组件。
- 历史不落库（后端语义：forward/exec 不建 job）——页面提示
  「此入口不产生任务记录；需历史请用主机详情的执行」。

## 状态矩阵

| 状态 | 表现 |
|------|------|
| 初始 | 无结果卡（执行后出现） |
| 执行中 | 按钮 spinner + 结果卡骨架「拨号中…」 |
| 成功 | exit_code + 输出 |
| 失败（连接类） | 结果卡错误态「无法连接目标（地址不可达 / 非 forward 模式）」+ 重试 |
| 失败（命令非 0） | 正常显示 exit_code + 输出（业务语义非错误） |
| 无 forward 主机 | 主机名下拉空 + 提示「没有 forward 模式主机——先在主机页创建」 |

## 交互细节

- Enter 执行；命令历史（本会话内最近 5 条，下拉可重选——纯前端，不落库）。
- 该页在 Sidebar 导航中放「主机」分组下的次级入口（图标 ⇄），与产品主线（持久连接 + agent_id 路由）区隔。
