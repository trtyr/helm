# 设计语言 — Vercel/Geist 风

Role: topic-capsule
Status: active
Read when: 写任何 helm 前端页面/组件前，先读本文对齐 tokens 与布局规范
Related: [路由地图](../routes/README.md)、[功能清单](feature-inventory.md)、[决策 002](../decisions/002-design-language-vercel-geist.md)

## One-Screen Summary

helm 前端采用 Vercel 的 **Geist** 设计语言：黑白灰高对比、1px 锐利边框、小圆角、
克制的微动效、内容优先的密度控制。暗色为主题第一公民，亮色为切换项。
tokens 以官方 CSS 变量（`--ds-*`）为权威，本文 hex 为参考值。

## 设计原则

1. **黑白灰即品牌**——色彩只用于语义（状态/交互/数据），绝不做装饰。
2. **内容优先**——chrome（导航/边框/底纹）退后，数据与操作前置；留白是层级工具。
3. **锐利几何**——1px 边框 + 小圆角（6/8/12），拒绝大圆角与大阴影的「泡泡感」。
4. **微动效**——150–200ms 的状态反馈（hover/出现/切换），不做页面级转场动画。
5. **密度服务专业**——运维工具信息密度高于消费产品；紧凑但不窒息。

## 色板

### 灰阶（10 阶语义系统，官方 `--ds-gray-100..1000`）

每阶有固定语义（官方约定）：100 默认背景 / 200 hover 背景 / 300 active 背景 /
400 默认边框 / 500 hover 边框 / 600 active 边框 / 700 高对比背景 / 800 hover 高对比 /
900 次要文字图标 / 1000 主文字图标。

| 阶 | 暗色（默认） | 亮色 | 语义 |
|----|------------|------|------|
| background-1 | `#000000` | `#ffffff` | 页面默认背景 |
| background-2 | `#0a0a0a` | `#fafafa` | 次级背景（嵌套面板） |
| gray-100 | `#0a0a0a` | `#fafafa` | 控件默认背景 |
| gray-200 | `#171717` | `#ededed` | 控件 hover 背景 |
| gray-300 | `#212121` | `#e0e0e0` | 控件 active 背景 |
| gray-400 | `#262626` | `#eaeaea` | 默认边框 |
| gray-500 | `#333333` | `#d4d4d4` | hover 边框 |
| gray-600 | `#404040` | `#c9c9c9` | active 边框 |
| gray-700 | `#333333` | `#ebebeb` | 高对比背景（强调按钮） |
| gray-800 | `#404040` | `#e4e4e4` | hover 高对比背景 |

## 字体（Geist Sans / Geist Mono）

- **Geist Sans**：UI 文字（正文、标签、导航）。
- **Geist Mono**：数据与身份标识——IP、agent_id、host_id、UUID、指标数值、时间戳、
  终端输出、代码。等宽是「机器数据」的视觉信号。
- 字号阶梯采用官方 Tailwind class 体系（`text-*`）：

| class | size/line-height | weight | 用途 |
|-------|------------------|--------|------|
| `text-heading-32` | 32/40 | 600 | 页面主标题（仅仪表盘） |
| `text-heading-24` | 24/32 | 600 | 区块标题 |
| `text-heading-20` | 20/28 | 600 | 卡片标题 |
| `text-heading-16` | 16/24 | 600 | 小节标题 |
| `text-label-16` | 16/20 | 500 | 表单标签、列表主行 |
| `text-label-14` | 14/16 | 500 | **系统默认文本**：菜单、表格、按钮 |
| `text-label-13` | 13/16 | 400 | 次级行、表头；数字用 tabular-nums |
| `text-label-13-mono` | 13/16 | 400 | 表格内机器数据（ID/IP/时间） |
| `text-label-12` | 12/16 | 400 | 三级文本、徽标 |
| `text-copy-14` | 14/24 | 400 | 说明段落、空态文案 |
| `text-copy-13` | 13/20 | 400 | 紧凑说明 |

- 数字一律 `tabular-nums`；表格数字列右对齐。

## 间距与网格（8pt）

| token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 图标与文字间隙、紧凑控件内距 |
| `space-2` | 8px | 控件内距、标签排布 |
| `space-3` | 12px | 表格单元格上下、按钮组间距 |
| `space-4` | 16px | 卡片内距（紧凑）、表单字段间距 |
| `space-6` | 24px | 卡片内距（标准）、卡片网格 gap |
| `space-8` | 32px | 区块间距、页头下缘 |
| `space-12` | 48px | 页面级留白（内容区上下） |
| `space-16` | 64px | 仪表盘大区块 |

页面留白基准：内容区左右 `space-8`（32px，宽屏 ≥1440 时 `space-12`）；
页头（标题 + 操作区）与内容 `space-8`；卡片之间 `space-6`；卡片标题与正文 `space-4`。

## 边框 / 圆角 / 阴影（materials 体系）

- **边框**：一律 `1px solid` gray-400，hover 升 gray-500。分隠除外（1px gray-400，
  不随 hover 变化）。聚焦环：`2px` blue-1000 外扩 2px。
- **圆角**：输入框/按钮/小控件 `6px`；卡片/下拉面板 `8px`；菜单/模态 `12px`；
  全屏层 `16px`（对应官方 material-base/medium/menu-modal）。
- **阴影**：页面内元素**不用阴影**（边框即层级）；仅浮层使用：
  下拉/tooltip `0 2px 4px rgba(0,0,0,.08), 0 4px 12px rgba(0,0,0,.16)`；
  模态再叠加一档 `0 8px 24px rgba(0,0,0,.24)`。

## 动效

| 场景 | 时长/缓动 |
|------|----------|
| hover / active 状态 | 150ms `ease-out` |
| 下拉/模态出现 | 200ms `ease-out`（透明度 + 4px 位移） |
| 页签切换 | 150ms（仅指示条滑动） |
| 实时数据刷新 | 无动画，直接替换（数字跳变不做过渡） |
| 骨架屏 | `pulse` 2s 循环，灰色 gray-100/200 交替 |

禁止：页面转场动画、大面积位移动画、视差。

## 全局布局框架

```text
┌────────────────────────────────────────────────────────────┐
│ Topbar 56px：Logo │ 全局搜索 ⌘K │ …spacer… │ 通知铃铛 │ 主题 │ 用户 │
├──────────┬─────────────────────────────────────────────────┤
│ Sidebar  │  Content（max-width 1440 居中，左右 32px 留白）   │
│ 220px    │  ┌───────────────────────────────────────────┐  │
│ 可折叠    │  │ PageHeader：title + 描述 + 右侧主操作      │  │
│ 至 64px  │  ├───────────────────────────────────────────┤  │
│ (纯图标)  │  │ 区块内容（卡片 / 表格 / 分栏）             │  │
│          │  │                                           │  │
│ 主机      │  │                                           │  │
│ 通知      │  │                                           │  │
│ 告警      │  │                                           │  │
│ 任务      │  │                                           │  │
│ 审计      │  │                                           │  │
│ 监听器    │  │                                           │  │
│ 设置      │  │                                           │  │
├──────────┴─────────────────────────────────────────────────┤
│ StatusBar 28px：WS 连接状态 │ 在线主机 n/m │ 版本           │
└────────────────────────────────────────────────────────────┘
```

- **Topbar**：高 56px，背景 background-1，底部 1px 边框；仅全局性元素。
- **Sidebar**：宽 220px（折叠 64px 纯图标）；导航项高 36px、圆角 6px、
  hover gray-200、激活 gray-200 + 左侧 2px blue-1000 指示条。
- **StatusBar**（底部）：实时链路的「仪表」——WS 断线全局可见（红点 + 重连中）。
- **密度**：表格行高 40px（默认）/32px（紧凑切换）；控件高度统一 32px（输入/按钮）；
  小按钮 24px。列表卡片内距 16px，仪表盘卡片 24px。

## 图标

- 线性图标（`@vercel/geistcn-assets` 或 lucide-react 同风格 1.5px 描边）。
- 尺寸 16px（内联）/20px（导航/按钮）；不填充、不彩色（语义色除外）。

## 主题

- **暗色为默认**（运维场景 + Vercel 风）；亮色可切换，持久化到 localStorage。
- 实现以 CSS 变量承载（`--ds-*`），主题切换即换变量组；组件只消费变量，不写死色值。
